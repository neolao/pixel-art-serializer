# Module: manual-grid-editor

**Role:** Wires manual grid adjustment to the screen: a draggable/resizable selection overlay on the original image plus a width/height form, for correcting the detected grid by hand.
**Files:** `src/manual-grid-editor.ts`
**Exports:** `createManualGridEditor(elements: ManualGridElements, onConfirm: (rect: SelectionRect, gridWidth: number, gridHeight: number) => void, onReset: () => void): ManualGridEditor`, types `ManualGridElements`, `ManualGridEditor`
**Depends on:** `modules/grid-selection.md`

`activate` seeds the selection to the whole image and pre-fills the width/height form with the given (typically auto-detected) grid size, then shows the overlay; `deactivate` hides it without side effects (a fresh image was selected). Dragging the selection body or one of its 8 handles (mouse, touch, or pen via Pointer Events, tracked on `window` so the gesture survives the cursor leaving the element) — or focusing a handle or the selection body and using arrow keys, Shift for a bigger step (keyboard) — updates the rectangle live via `modules/grid-selection.md`, but only calls `onConfirm` once the interaction ends (drag release or a keyboard nudge), never on every intermediate move, so the caller's pipeline recompute isn't triggered continuously during a drag. Changing the width/height inputs validates them (a whole number of at least 1) before calling `onConfirm`, showing an inline error and leaving the caller's last valid result in place otherwise. The selection element's `--manual-grid-cols`/`--manual-grid-rows` CSS custom properties drive the grid-line background (see `src/style.css`) so the subdivision lines always match the current grid size. DOM-safe wiring (rendering, drag/resize math, keyboard nudging, form validation) is unit-tested with a stubbed `getBoundingClientRect`, the same technique `modules/reconstruction-editor.md` uses for its canvas painter; the actual crop-and-recompute the confirmation triggers is `modules/result.md`'s `computeManualDetection`, wired by `modules/app.md`.
