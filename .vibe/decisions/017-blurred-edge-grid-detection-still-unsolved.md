# Grid detection on heavily blurred/anti-aliased edges remains unsolved — no production change

**Context:** Backlog item 014, a dedicated research spike (`spikes/014-robust-grid-detection/`), revisited the "known limitation" already flagged in `decisions/002-grid-and-palette-algorithms.md` and `decisions/004-grid-detection-pooled-line-scanning.md`: a real, Product-Owner-confirmed 16×16 pixel-art image (`fixtures/candidate-images/pixel-art-mario-sprite-blurred-border.png`) whose logical-pixel edges are soft/blurred throughout (not only at its decorative border) is detected as having no grid at all.

**Decision:** Keep the current production algorithm (pooled full-line run-length mode) unchanged. Do not adopt either candidate tried in this spike. The limitation stays open, now with concrete diagnostic evidence instead of a general description.

**Reason:** Direct pixel inspection of the sample showed anti-aliasing noise at *every* internal color-region boundary, not just the outer border — trimming an 8% margin left the noise dominance unchanged. Two candidate replacements were implemented and run for real against every image in `fixtures/candidate-images/` (5 non-pixel-art icons, 3 previously-correct pixel-art images, the new blurred sample):
1. **Harmonic run-length matching / autocorrelation of an edge-density profile** — scores a candidate cell size by how much of the pooled signal falls near its multiples. Fails because small candidate sizes (2–10px) trivially "explain" most of the signal (their multiples are so closely spaced that almost any length matches one), so they always outscore the true, larger cell size. Confirmed numerically: candidate size 8 outscored the true ~42px size 5794-to-4260 on raw coverage. Also regressed both previously-correct samples (`pixel-art-cat.png` 38→116, `pixel-art-cat-grid-drawing.png` 64→332) and produced false grids on all 5 confirmed non-pixel-art icons.
2. **Block-uniformity with an explored starting offset** (extends decision-002's rejected block-uniformity with an offset search, to fix its origin-alignment sensitivity) — a loose uniformity threshold (0.85, averaged) again let trivially-uniform small blocks win everywhere; a strict, largest-first threshold matching the original spike's semantics (0.97, all-or-nothing per block) correctly stopped the icon false positives but then also missed the two previously-correct pixel-art images (`pixel-art-cat.png`, `pixel-art-cat-grid-drawing.png` both regressed to size 1) and still found nothing on the target sample. No threshold in between was found (or is likely to exist) that keeps both properties, since the same per-pixel color tolerance has to separate real noise from real signal at every candidate size simultaneously.

Both failure patterns are structural, not a tuning miss: separating a real repeating cell size from anti-aliasing noise needs information neither candidate's scoring uses (e.g., true periodicity via phase-aware frequency analysis with an origin/offset search, which decision-002 already flagged as a much larger undertaking than a single spike). Shipping either candidate would trade one known failure mode (this specific image type) for a new, more common one (false grids on non-pixel-art icons, or missed grids on already-working pixel art) — a net regression for production use.

**Rejected alternatives:** the two candidates described above, both implemented and run for real (not just reasoned about) — see `spikes/014-robust-grid-detection/`; a border-only crop, ruled out first by direct pixel inspection before writing any candidate algorithm, since the noise was confirmed to be pervasive rather than border-only.

**Left for future work:** a proper period-detection algorithm robust to both jitter and heavy edge noise (e.g. phase-aware autocorrelation with an explicit offset search, or spectral/FFT-based peak detection) is a research undertaking on the scale of the original `decisions/002` spike, not a bounded bug fix — should be scoped as its own dedicated backlog item if a future business need justifies the investment. `pixel-art-mushroom-native-16x16.png` (added to the fixture set from this spike, confirmed genuine pixel art at native resolution — not upscaled) is unrelated to this limitation but worth keeping as a fixture for future confidence-scoring work.
