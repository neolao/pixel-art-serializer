## Project overview

A static, client-side website (hosted on GitHub Pages) that takes an image as input and serializes it into a JSON description of its pixels. The goal is to detect whether an image is pixel art of this kind. Detection first has to recover the "real" pixel size (the logical pixel grid, which differs from the image's raw dimensions), then index the image's color palette, since pixel art also constrains the number of distinct colors used.

**Stack:** TypeScript / Vite (vanilla-ts template) / Vitest / Biome
**Type:** frontend (static site, no backend)
