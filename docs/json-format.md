# The exported JSON format

This is the shape of the file downloaded from the app (`serializePixelArt`'s output, in `src/serializer.ts`). A machine-checkable version of this same shape is published at [`pixel-art-serialization.schema.json`](pixel-art-serialization.schema.json) (JSON Schema, draft-07) — validate a downloaded file against it instead of re-implementing these rules by hand.

## Shape

```json
{
	"formatVersion": 1,
	"gridWidth": 2,
	"gridHeight": 1,
	"palette": [
		{ "index": 0, "color": "#00000000", "reserved": true },
		{ "index": 1, "color": "#ff0000ff", "reserved": false }
	],
	"pixels": [0, 1]
}
```

## Fields

- **`formatVersion`** — an integer, currently always `1`. Bumped whenever a future change to this shape would break a consumer relying on the previous one. Check it before assuming any field below, the same way you'd check an API's version before parsing its response.
- **`gridWidth`** / **`gridHeight`** — the image's logical size, in pixel-art pixels (its detected grid), not the raw pixel dimensions of the source image file.
- **`palette`** — every distinct color the image uses, each an object:
  - **`index`** — this color's stable identifier, referenced by `pixels` below. **Not the same as this entry's position in the `palette` array.** Removing a color (via the app's manual editor) never renumbers or compacts the array, so a palette can have entries `0, 1, 3` with no `2` — the array's length tells you nothing about the highest index in use.
  - **`color`** — the color as one 8-digit hex string: 2 hex digits each for red, green, blue, then alpha (`"#rrggbbaa"`; `00` = fully transparent, `ff` = fully opaque).
  - **`reserved`** — `true` for exactly one entry, always at `index: 0`: a permanent, fully-transparent color (`color` is always `"#00000000"`) that exists even in an image with no transparency of its own, and can never be removed, recolored, or displaced by another color. Every other entry has `reserved: false`.
- **`pixels`** — one palette `index` per logical pixel, in row-major order (left to right, then top to bottom): `gridWidth * gridHeight` entries in total.

## Consuming this file

- Look up a pixel's actual color by matching its `pixels` value against a palette entry's `index` — never against the palette array's position.
- A consumer that only cares about "is this pixel visible at all" can treat `reserved: true` (or, equivalently, an alpha of `00`) as fully transparent without inspecting the RGB channels, which are meaningless for that entry.
- Check `formatVersion` first; a file with a different value may not match the shape described here.
